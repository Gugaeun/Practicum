## 📌 과제 4 - 방탈출 게임 "FRACTURE — 시간의 균열" 🚧 *(진행 중)*

HTML/CSS/JS로 직접 제작 중인 스토리 기반 방탈출(escape room) 웹 게임입니다. 현재 기능 구현과 UI/UX 개선을 반복하며 계속 다듬는 중입니다.

- [소스 코드](https://github.com/Gugaeun/Practicum/tree/main/Web_Practicum/escape-game/Escape_Hardcore)
- 스테이지별 테마와 퍼즐, 상호작용 가능한 오브젝트, 힌트(일기장) 시스템 등을 설계
- 진행 중인 개선 방향: 상호작용 오브젝트 표시, 퍼즐 정답 랜덤화, 스테이지별 분위기(벽지·소품) 보강, CSS/JS 모듈 세분화 등
- 코드 규모: HTML/CSS/JS 합쳐 약 5,000줄

> 완성 전 단계로, 기능·디자인이 계속 업데이트되고 있습니다.

---

## 🛠 사용 기술

- HTML
- CSS
- JavaScript
- Netlify (배포)

## 💡 배운 점

- HTML / CSS를 활용한 반응형 웹 페이지 구조 이해
- Netlify를 통한 정적 사이트 배포 경험
- 게임 로직(상태 관리, 라운드 진행, 승패 판정)을 순수 JavaScript로 구현하는 경험
- 규모가 큰 프로젝트(방탈출 게임)를 진행하며 요구사항을 정리하고 단계적으로 개선해나가는 과정 경험
