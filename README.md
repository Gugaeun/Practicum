# 📚 Practicum

대학교 수업에서 진행한 실습과 프로젝트를 언어·분야별로 정리한 저장소입니다.
자료구조·알고리즘 기초부터 UI 프로그램, 영상 처리, 웹 프로젝트까지 다양한 실습을 포함하고 있습니다.

---

## 📁 Repository Structure

| 분야 | 폴더 | 내용 |
|---|---|---|
| 🐍 Python | [py_Practicum](https://github.com/Gugaeun/Practicum/tree/main/py_Practicum) | 자료구조(List·Set·Stack·Queue·Deque·우선순위 큐) 직접 구현, DFS/BFS 미로 탐색, Flet 기반 UI 프로그램(계산기·볼링 점수판 등) |
| 💻 C++ | [C++ Practicum](https://github.com/Gugaeun/Practicum/tree/main/C%2B%2B%20Practicum) | 자료구조 및 알고리즘 과제 |
| 👁 Computer Vision | [CV_Practicum](https://github.com/Gugaeun/Practicum/tree/main/CV_Practicum) | OpenCV 기반 영상 처리 (노이즈 제거, Sobel·Canny 엣지 검출 등) |
| 🌐 Web | [Web_Practicum](https://github.com/Gugaeun/Practicum/tree/main/Web_Practicum) | HTML/CSS/JS 웹 UI 실습, TodoList(Netlify 배포), 미니 게임 2종, 방탈출 게임(🚧 진행 중) |

각 폴더의 README에 실습별 상세 설명, 예제 코드 링크, 결과 화면이 정리되어 있습니다.

## 💡 배운 점

- 여러 언어(Python/C++)로 같은 자료구조를 구현해보며 각 언어의 특성과 공통 원리를 함께 이해
- DFS/BFS 등 탐색 알고리즘을 미로 탐색 문제에 직접 적용
- OpenCV로 영상 처리 기초(필터링, 엣지 검출)를 실습
- 정적 웹사이트를 실제로 배포(Netlify)하고, 순수 JavaScript로 게임 로직을 구현하는 경험
- 완성까지 여러 차례 요구사항을 정리하고 개선해나가는 프로젝트 진행 과정(방탈출 게임) 경험
